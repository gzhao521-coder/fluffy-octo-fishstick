1. 用手机浏览器打开：
   https://gzhao521-coder.github.io/fluffy-octo-fishstick/?v=20260811

3. 如果手机主屏装的是旧版应用，删除后重新添加。

   等页面完全显示后再关闭，下次从主屏打开会走新缓存。
