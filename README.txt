这一版主要修数据安全和几个明显的问题，不改数据结构，旧数据可以原样读取：
1. 修复补剂"用药日志"被清空：以前点一下补剂的 ✓ 按钮会删掉当天记录，

8. 手机端打卡按钮从 40px 恢复到 44px；底部导航未选中项的文字对比度从约 1.3:1 提到约 6.3:1。
